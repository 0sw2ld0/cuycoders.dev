Privacidad y condiciones

Este aviso es de Alfalfa Cloud, el servicio de modelos en la nube con códigos de cortesía. AlfalfaCode, el programa, es otra cosa: se instala en tu Mac y no manda nada a CuyCoders salvo que uses Alfalfa Cloud o el botón «Reportar un error».

Última actualización: 9 de noviembre de 2026. Responsable: CuyCoders, soporte@cuycoders.dev.

En pocas palabras

No guardamos el contenido de tus mensajes. Pasan por el servidor camino del modelo y no se escriben en ninguna base de datos. Sí guardamos tu código, cuánto gasta cada día y cada mes, el nombre del Mac donde lo activaste y los reportes de error que mandes.

Qué datos guarda el servicio

DatoPara qué
Tu códigoPara reconocerte. Se guarda solo su huella (hash), nunca el código tal cual, con el nombre que CuyCoders le puso al crearlo, sus topes, sus modelos y su fecha de caducidad.
El Mac donde lo activasteSu nombre (el de Ajustes del Sistema ▸ General ▸ Información) y la llave pública del Secure Enclave, para que el código solo funcione en ese Mac.
Uso por día y por mesDólares gastados, tokens de entrada y de salida y número de peticiones por proveedor. Sirve para los topes y para la barra de cuota de la app.
Reportes de errorLo que escribes, el contacto si lo das, la versión de AlfalfaCode, tu sistema y el registro de diagnóstico que adjunta la app (hasta 64 KB). Si no tienes código, en vez de tu IP se guarda una huella de ella, solo para limitar los reportes.
Registros técnicos del servidorPor cada petición, el servidor anota la IP, la ruta, el método y el código de respuesta en el registro del sistema. Sirven para ver fallos y ataques, y se borran cuando el sistema rota sus registros.
Marcas de un solo usoCada petición firmada lleva un número que no se puede repetir. Se guarda unos minutos para impedir que alguien reenvíe una petición tuya.

Además, mientras el servicio está encendido, la IP de cada conexión se usa en memoria para limitar las peticiones por minuto y frenar a quien prueba códigos a ciegas. Esa cuenta no se escribe en disco.

Tus mensajes

Lo que le pides al modelo, los archivos y las imágenes que AlfalfaCode le enseña y sus respuestas atraviesan el servidor y se mandan al proveedor del modelo. Alfalfa Cloud no los guarda. Solo anota cuántos tokens usaron, para el coste.

A quién se los pasa

  • OpenAI, para GPT-6 Luna. El servicio le pide que no guarde la conversación (store: false). Aun así, OpenAI aplica su propia política, que puede conservar datos un tiempo para vigilar abusos.
  • Anthropic, para Claude Haiku 5.5. Su API no tiene una opción para pedir que no guarde la conversación, así que Anthropic aplica su propia política, que puede conservar datos un tiempo para vigilar abusos. Para abaratar cada petición, Anthropic guarda en caché el principio de la conversación durante 5 minutos. Con la conversación solo va un identificador corto de tu código, nunca el código ni tu nombre.
  • Ollama, para los modelos de Ollama Cloud, con su propia política de privacidad.
  • DigitalOcean, donde está el servidor y su base de datos.

No vendemos datos ni los usamos para publicidad. Ni el servicio ni esta web usan cookies ni analítica. Esta web la sirve GitHub Pages, que registra las visitas según su propia política.

Cuánto tiempo

  • El código, su Mac y su uso se conservan mientras el código exista. Si lo borramos, o lo pides tú, se borran con él.
  • Los reportes de error se conservan hasta que se resuelven o pides que se borren.
  • Cada día se hace una copia de seguridad de la base de datos, y cada copia se borra a los 14 días.
  • Los registros técnicos duran hasta que el sistema los rota.

Ver o borrar tus datos

Escribe a soporte@cuycoders.dev desde el correo con el que te dimos el código, o indicando tu código, y te diremos qué hay guardado o lo borraremos. Borrar los datos de un código lo desactiva.

Lo que hace la app

AlfalfaCode guarda sus sesiones y ajustes en tu Mac (~/.alfalfa) y sus claves en el Llavero. Por su cuenta solo se conecta con:

  • el proveedor de modelos que elijas (Ollama, OpenAI, otro compatible o Alfalfa Cloud);
  • los buscadores web, desde tu conexión, cuando el agente busca algo;
  • GitHub, para ver si hay una versión nueva;
  • Alfalfa Cloud, cuando mandas un reporte de error.

Condiciones de uso

  • Alfalfa Cloud es un servicio de cortesía, por invitación y sin coste para ti. Se da tal cual, sin garantías de disponibilidad, calidad ni resultados.
  • CuyCoders puede cambiar los modelos y los topes, pausar o retirar cualquier código y apagar el servicio en cualquier momento, sin aviso.
  • Tu código es personal: no lo compartas, no lo revendas y no intentes saltarte sus topes.
  • No lo uses para nada ilegal, para dañar a otros ni contra las políticas de uso de OpenAI, Anthropic y Ollama.
  • Lo que hagan los modelos en tu proyecto es responsabilidad tuya: revisa los cambios antes de aceptarlos y de publicarlos.

Si cambiamos este aviso, cambiará la fecha de arriba. Para cualquier duda: soporte@cuycoders.dev.
